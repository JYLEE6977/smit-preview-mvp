## 2. 색상과 이미지

**확인·브라우저:** body 배경 `#FFFFFF`, 일반 본문 `#444444`, 히어로 제목·내비게이션 `#FFFFFF`, 브랜드 CTA 내부 배경 `rgb(67,126,247)` 즉 `#437EF7`. 입력창은 흰 배경·`#CCCCCC` 테두리다. 히어로는 단일 CSS 배경만으로 구성되지 않는다. 데스크톱에서는 산·차량·전경의 absolute 이미지 레이어가 object-fit cover로 겹치며, 모바일에서는 데스크톱 레이어가 display none으로 바뀌고 모바일용 배경 이미지를 사용한다. 어두운 하단 fade 그라데이션도 확인했다.

**해석:** ‘밝은 본문 영역 + 몰입감 있는 사진 무대’의 대비가 핵심이다. 이미지 위 문구를 왼쪽에 모으고 주 피사체를 다른 쪽에 남긴다. 사진의 자연색을 주인공으로 두며 강조색은 주요 행동에 집중한다.

**채택:** 실제 학교·서울 사진과 빨간 CTA를 사용한다. 레퍼런스의 차량·풍경·로고·영상·상업 문구는 가져오지 않는다. SMIT에서는 한 장의 사진과 명시적인 어두운 스크림으로 구현하며 과도한 패럴랙스는 사용하지 않는다.

## 5. 컴포넌트·상태

- **확인:** CTA는 링크 wrapper 안쪽의 `.button-content`가 색·테두리·padding을 담당한다. 주요 CTA padding 16px 20px, radius 8px, 높이 약 52.8px. 버튼 화살표가 진행 방향을 안내한다.
- **확인:** 사진 카드에는 전체 클릭 영역, 짧은 분류·큰 제목·설명이 있다. 관찰된 기본 카드 box-shadow는 none이다.
- **확인:** 입력창 font-size 16px, 높이 60px, radius 8px, padding `16px 12px 16px 16px`, textarea 높이 180px.
- **확인:** 키보드 이동 후 CTA 링크의 focus-visible true, computed outline은 `auto 0.8px`였다. SMIT에서는 이 UA 기본값 대신 명시적 포커스 링을 유지한다.
- **확인:** 문의 submit은 관찰 시 disabled 상태였다. 배경은 브랜드 파랑, transition 0.3s였다. disabled 원인이나 정상 제출 결과는 미확인이다.
- **미확인:** 마우스 hover의 전후 색·아이콘 애니메이션, 제출 성공/실패, 영상 재생, 드롭다운 전체, 슬라이더 전체 조작, OS reduced-motion에 대한 원본 대응. 상태를 추정하여 실제 확인으로 기록하지 않는다.

## 6. SMIT 채택과 충돌 해결

우선순위는 **학교의 빨간색·영문 서비스·기존 기능 보존 → Drivelodge의 전체 이미지 랜딩 → 이전 Reference Lab의 즉시 피드백 원칙**이다.

- 채택: 화면을 가득 채우는 사진, 이미지 위 투명 헤더와 흰 글자, 좁은 텍스트 묶음, 주요/보조 CTA, 여유 있는 본문 섹션, 간결한 8~12px 모서리.
- 유지: 실제 SMIT 사진·출처, 빨간 버튼, 하루 선택·수업·주간표·신청 흐름, 키보드 포커스와 disabled 처리.
- 제외: 파란 브랜드색, 차량·영국 풍경·로고·문구, 2200px 패럴랙스 높이, 영상·슬라이더 라이브러리, 불필요한 대규모 메뉴. 모바일은 현재 작은 서비스에 맞는 직접 행동 버튼을 유지한다.
- 한글: 시스템 폰트 fallback과 단어 단위 줄바꿈을 유지하되 실제 제품 문구는 영어다.

| h2 | 20px | 별도 굵기 지정 없음 | 행간 상속, 자간 -0.6px |
| h3 | 15px | 별도 굵기 지정 없음 | 마진 `20px 0 8px` |
| 입력 라벨 | 14px | 700 | 행간 상속 |
| 입력 컨트롤 | 기본 본문 폰트 상속 | 상속 | `font:inherit` |
| 버튼 | 13px | 750 | 행간 상속 → 약 21.45px |
| 도움말·푸터 | 12px | 별도 지정 없음 | 행간 상속 |
| 선택 사항 표기 | 11px | 400 | 보조 텍스트색 |
| 출력 textarea | 13px | 상속 | `ui-monospace, Consolas, monospace`, `1.8` → 23.4px |

**[추정·계산]** 1280px 너비에서 h1은 49px, 행간 약 59.78px이다. 390px에서는 h1이 최솟값 30px, 행간 36.6px이다.

**[미확인]** 실제로 선택되는 시스템 폰트와 한글 대체 폰트, h1·h2·h3의 브라우저 기본 굵기, 가변 굵기 750·850의 실제 지원 여부, 글꼴 합성, 줄 수·줄바꿈. 한글 단어 단위 줄바꿈을 보장하는 `word-break:keep-all` 선언은 원본에 없다.

### 이미지에 대한 확인

**[확인·소스]** 원본에는 `<img>`, `<svg>`, `<canvas>`, 외부 stylesheet 링크, CSS `url()` 선언이 각각 **0개**다. 로고는 `R` 텍스트와 CSS 사각형이며, 시각적 안내는 카드·원형 번호·단계 화살표로 구성한다. 따라서 이 레퍼런스에서 사진 선택, 이미지 비율, 크롭·갤러리 규칙을 추출할 근거는 없다.

**[제안]** SMIT의 실제 학교·주변 지역 이미지는 기존 출처를 유지한다. 사진을 수업·등교·수업 후 활동 선택 카드와 연결해 ‘내가 이곳에 있다면’이라는 상상을 돕는 방향은 우리 서비스의 별도 설계로 다룬다. 이 레퍼런스가 그런 이미지 체험을 제공한다고 주장하지 않는다.

## 6. 상태와 인터랙션

| 상태 | 확인한 정의 / 구현 | 실제 조작 확인 |
| --- | --- | --- |
| hover | `.btn:hover { filter:brightness(.95) }` | 미확인 |
| focus | 전역 `:focus-visible`: 3px `#B48124` outline, offset 4px | 키보드 진입·잘림·대비 미확인 |
| disabled | `.btn:disabled`: opacity 0.5, cursor wait | 실제 일시 상태·스크린리더 전달 미확인 |
| 복사 중 | `copy` 핸들러가 버튼을 disabled로 바꾸고 `finally`에서 복구 | 미실행 |
| 선택 탭 | `[aria-selected=true]` 녹색 배경·흰 글자. JS로 tabindex와 aria-labelledby 갱신 | 미실행 |
| 체크 완료 | `:has(input:checked)`로 라벨 보조색, progress·문구 갱신 | 미실행 |
| 입력 | input 이벤트가 출력 프롬프트를 갱신하고 localStorage 저장을 시도 | 미실행 |
| readonly | 출력 textarea에 readonly 지정. 별도 readonly 색상 규칙 없음 | 텍스트 선택·복사 미확인 |
| 오류 / 저장 불가 | 코드에서 URL 오류를 status에 표시하고 해당 필드에 focus. localStorage 실패 안내도 존재 | 미실행 |

**[확인·소스]** 탭에는 좌우 화살표, Home, End 키 처리가 있으며 상태 영역은 `role=status`, `aria-live=polite`로 선언되어 있다. `@keyframes`, `animation:`, `transition:` 선언은 발견하지 못했다. 움직임 효과보다 선택·입력에 따른 즉시 내용 갱신을 사용하는 구조다.

**[미확인]** 실제 hover·키보드 포커스·disabled 전환, clipboard 권한·대체 복사, 다운로드, 초기화 대화상자, 브라우저 저장 복구, 스크린리더 동작. 분석을 위해 사용자의 저장된 입력을 변경하거나 초기화하지 않았다.

## 7. 모바일에서 달라지는 규칙

다음은 **[확인·소스] 미디어쿼리 선언**이며 실제 휴대전화 확인 결과가 아니다. `viewport` 메타 태그는 `width=device-width,initial-scale=1`이다.

| 너비 조건 | 변화 |
| --- | --- |
| 850px 이하 | `.hero`, `.layout`을 1열로 전환 |
| 850px 이하 | 히어로 gap 22px, 세로 padding 30px |
| 850px 이하 | `.sticky`를 `position:static`으로 전환 |
| 850px 이하 | `.wrap` padding `20px 18px 40px` |
| 850px 이하 | 카드 padding 21px, 출력 textarea 최소 높이 360px |
| 420px 이하 | `.row` 입력 묶음을 1열로 전환 |
| 420px 이하 | 헤더 tag 10px, 로고 16px, 헤더 gap 8px |
| 420px 이하 | 푸터 세로 배치, gap 8px |
| 너비와 무관 | `.flow`, `.actions`는 flex-wrap 허용 |
| 너비와 무관 | 버튼·링크·입력 컨트롤에 `touch-action:manipulation` |

**[미확인]** 850/851px 및 420/421px 경계에서의 실제 전환, 320~390px 헤더 태그 충돌, 긴 URL·한글 본문의 줄바꿈, 소프트 키보드 사용, 터치 영역. CSS 수치만으로 터치 사용성과 가로 넘침이 없음을 보장할 수 없다.

참고로 print 규칙도 존재하지만 인쇄 미리보기는 실행하지 않았다. 인쇄 시 단일 열, sticky 해제, 버튼·탭·status 숨김 등은 선언만 확인했다.

## 8. SMIT 프로젝트에 적용할 요소와 제외할 요소

아래는 모두 **[제안]**이며 이번 작업에서 사이트 코드를 변경하지 않았다.

### 적용할 후보

| 요소 | SMIT에서의 적용 방향 | 목적 |
| --- | --- | --- |
| 역할이 분리된 색상 | 배경·본문·행동·보조색의 구조를 참고하되 SMIT 빨강 `#AE152D`, `#CC3A3A`를 유지 | 브랜드 일관성과 행동 위계 |
| 넉넉한 여백과 카드 | 공통 카드의 padding과 간격을 통일. 참고 수치는 gap 24px, 모바일 padding 21px이며 최종값은 다음 설계 단계에서 결정 | 사진·수업·일정 정보를 작은 단위로 이해 |
| 단계 안내 | ‘수업 맛보기 → 나의 일주일 → 신청’ 진행 상태를 짧은 영문 라벨로 표시 | 지금 할 행동을 명확하게 안내 |
| 즉시 피드백 | 수업·활동 선택 시 결과 카드와 주간 계획이 즉시 갱신되는 기존 기능을 시각적으로 강화 | 자신의 선택이 미래 생활에 반영된다는 느낌 |
| 선택 상태 | 탭의 aria-selected처럼 버튼·카드의 선택을 색상과 텍스트/아이콘으로 함께 표시 | 색에만 의존하지 않는 확인 |
| 완료·진행 표현 | 레퍼런스의 진행 수치처럼 체험 완료·계획한 활동 수를 작게 표시하는 방안 검토 | 지나친 게임화 없이 체험 동기 제공 |
| 키보드 포커스 | 공통 focus-visible 링과 offset, 명확한 처리 중/disabled 상태 | 마우스·키보드 모두 사용 가능하게 설계 |
| 반응형 단순화 | 2열을 1열로 전환하고, 모바일에서 sticky를 해제하는 원칙 참고 | 휴대전화에서 읽고 선택하기 쉽게 구성 |
| 설명의 점진적 공개 | 상세 설명을 펼침 영역으로 옮기는 방안 검토 | 긴 텍스트가 상상을 방해하지 않게 구성 |

### 적용하지 않을 요소

- **녹색·연두색 팔레트의 직접 복제**: 학교의 기존 빨간색 지침과 충돌한다.
- **Reference Lab의 R 로고·워크북 태그·실습 문구**: SMIT 지원자의 과제와 무관하다. 서비스 화면은 기존 영문 지침을 유지한다.
- **입력 폼과 프롬프트가 중심인 2열 화면 전체**: 교육용 도구의 구조이므로 메인 페이지에 그대로 가져오지 않는다.
- **메인 화면의 큰 readonly 코드 출력창**: 지원자에게 개발 도구를 노출하는 흐름이 된다.
- **없는 사진·애니메이션 규칙을 레퍼런스에서 가져왔다고 설명하는 것**: 원본에 근거가 없다. 사진 기반의 즐거운 상상은 우리 서비스에 맞게 별도로 설계한다.
- **앰버색 포커스 링과 750/850 굵기를 검증 없이 그대로 확정**: SMIT 팔레트와 시스템 폰트에서 실제 대비·구현을 확인한 후 결정한다.
- **현재 콘텐츠 최대 너비 1160px를 1200px로 즉시 변경**: 1200px는 레퍼런스 수치다. 기존 학교 사진·체험 카드의 균형을 확인한 후 선택한다.
- **Supabase RLS, 공개 키 방식, 신청 저장 성공·실패 처리의 변경**: 디자인 분석 범위 밖이며 기존 기능을 보존한다.

## 미확인 사항과 후속 검증

이번에 확인한 것은 소스 선언과 코드 구조다. 브라우저에서 실제 화면을 보려던 시도는 프로토콜 정책으로 차단됐다. 접근 가능한 HTTP(S) 레퍼런스 URL이 제공되면 다음을 추가 확인할 수 있다.

1. 데스크톱 1280px와 모바일 390px에서 실제 viewport 및 DOM 박스 크기를 기록하고 화면을 캡처한다.
2. 850/851px, 420/421px에서 그리드와 헤더 전환을 확인한다.
3. computed style과 실제 사용 폰트, 제목 줄바꿈, 카드·입력창 너비를 확인한다.
4. hover, 키보드 focus-visible, 선택 및 처리 중 disabled를 실제로 조작한다.
5. 원본에 없는 사진 연출은 SMIT용 별도 제안으로 분리하고, 사진 크롭·대비·모바일 가독성을 확인한다.

**작업 범위:** `docs/design-reference.md`만 신규 작성했다. `index.html`, 기존 지침·설정·데이터 연결은 수정하지 않았으며, Git 커밋·푸시 및 배포도 실행하지 않았다. 기존 미추적 파일 `image.png`, `RE.jpeg`는 그대로 두었다.
