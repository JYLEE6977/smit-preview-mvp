# SMIT Preview MVP

A responsive English-language preview for prospective international SMIT students. Built as a standalone `index.html`, with red branding and images from the official school website.

- Sample classes, skill and career feedback, and an editable weekly planner.
- Interest form: name, email, and an optional message.
- Supabase `public.applications`: anonymous visitors can insert only. Reading, updating, and deleting applications are denied.
- The HTML contains only a public Supabase publishable key. Account tokens, database passwords, and service-role keys are excluded.
- Vercel imports this GitHub repository and automatically deploys pushes to `main`. No CLI deployment is required.

Update the site, commit your changes, then run `git push origin main`.

Illustrative classes and schedules are not confirmed SMIT course offerings. Photos: https://global.smit.ac.kr/
